# Nozmie

Smart teleport and utility access for World of Warcraft.

## What is Nozmie?

Nozmie detects teleport, portal, and utility requests in chat and gives you instant, one-click access to your spells and items.

## Key Features

*   Instantly cast teleports, portals, and utilities from chat requests
*   One-click banner for fast spell/item use
*   Utility Page: see all your teleports and utilities in one place
*   Customizable chat channel monitoring and suppression filters
*   Blacklist to ignore unwanted requests
*   Minimap icon for quick access

## Usage

*   Type `/noz` or `/nozmie` to open the Utility UI
*   Use `/noz settings` for addon options
*   Click the minimap icon to open the utility page, view the last banner or access settings
*   Utility Page: `/noz utility` to browse all available spells and items

## Why Nozmie?

*   Fast, one-click actions—no searching or typing
*   Only shows spells and items you can actually use
*   Prevents false positives with smart keyword matching
*   Clean, organized UI for all your utilities

## Commands

| Command                      |What it does                    |
| ---------------------------- |------------------------------- |
| <code>/noz</code>            |Open Utility UI                 |
| <code>/nozmie</code>         |Open Utility UI                 |
| <code>/noz settings</code>   |Open settings panel             |
| <code>/noz minimap</code>    |Toggle minimap icon             |
| <code>/noz last</code>       |Show last banner                |
| <code>/noz blacklist</code>  |Show current blacklist          |
| <code>/noz blacklist &amp;lt;words&amp;gt;</code> |Set blacklist (comma-separated) |

## Compatibility

*   Supports English, German, Spanish, French, Russian, Chinese (Simplified/Traditional), Korean, Portuguese
